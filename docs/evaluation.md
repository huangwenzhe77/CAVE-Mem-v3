# 冻结策略与完整任务评估

当前逐卡状态见 [任务卡](task_cards.md)。本页区分离线训练候选、独立验证任务、最终冻结 test；只有对应接口验收后才能使用。所有 fixture 只是软件检查。

## 冻结与验证执行

`freeze-policy` 创建自包含 JSON 包，绑定完整 manifest、冻结历史库、actor/encoder 身份、StudySpec、检查点抽样、暴露规则和策略参数。学习策略编包时重核原始训练/校准证据，执行推断只读包内参数。改变保守规则阈值会改变包身份；不能把训练候选的可行性直接转移给加了规则后的实际策略。

`collect-policy-validation` 从 validation/selection 任务起点运行同一个活环境，最多在一个检查点作一次决策。先产生并缓存 a0、检索并冻结 x，然后计算冻结规则/策略。Silent 执行缓存动作；Remind 临时提示一次并允许重提，动作仍经过工具权限验证。学习策略没有明确收益支持或风险校准支持时回 Silent。

无检查点、无记忆或无干预预算都保留完整任务和终局分母。剩余 actor 调用为0时仍可执行已缓存的 a0；R≥1 时与既有协议一致，只给普通续跑 R−1 次调用，不把 Silent 未用的提醒槽另行借出。无终局、pending 和基础设施错误保留未知，不能补成失败。完成后重入只读；不明外部调用不会自动重试。

只读入口为 `summarize-policy-validation --run <directory>`。它从原始事件与冻结输入重算结局、费用、决策及全部计划分母。准备、决策/提醒构造、实际分支费用分开计时且只累加一次；本地计时重核不重新作为实验费用。

## 策略类型与解释

冻结配置支持 no_memory、silent、always_remind、similarity、source、applicability、exposure、hard_tristate 规则，以及 supervised、bandit、no_risk_bandit 学习策略。相似度阈值与学习后保守规则必须显式固定。主库只含 v=1 时，source 与 always_remind 在同一资格门禁下可能完全相同；不能把名字不同当作不同实验行为。记忆规则对照是组件实现，不是 ExpeL/MemRL 等原系统复现。

`no_memory` 是普通 actor 基线：显式关闭检查点抽样，不检索、编码、构造记忆特征、运行 gate 或重提提醒动作，普通 actor 可用全部调用预算。它仍记录每次实际模型/工具调用及完整终局。`silent` 是保留检索/特征/草稿和提醒预留槽的组件基线，两者不能互换命名。冻结包仍绑定研究配置与库身份用于可比性检查，但 no_memory 任务执行不使用记忆输入。

同一套后置保守规则用于学习策略；无风险训练对照因此也不是取消所有运行规则。包记录原始和有效提醒概率，后续选型必须基于实际冻结执行策略。单活会话仅观察一臂，不产生个体配对 H/rescue；若需要配对风险证据，应另用经审核的匹配检查点协议。

完整任务评估应报告成功/未知、效用、覆盖、提醒、绝对 token/工具/actor 次数、耗时和费用。训练时 selected_gate_actor_calls 预算仅为局部干预口径，不等于完整任务费用。未执行的真实 benchmark、两档模型和外部系统基线仍需实际运行与可审阅配置。

## 预先登记选型计划

`plan-policy-selection` 固定候选包、未来 rollout 目录、独立配对审核目录、选择锁路径和 SelectionConfig；所有输出路径必须尚不存在、互不包含，且不能落入原始证据目录。`collect-policy-selection` 按计划产生新记录，计划绑定进入 live run 与原始 prepared run 的哈希，不能用旧日志加说明文件代替。`select-policy` 只读重核后写不可覆盖的选择锁。

所有登记候选必须完成完整任务且结局/效用已知，否则整个计划 no_selection，不能只挑剩下的候选。完整任务的等任务平均效用决定排名，同分按事先固定的候选 ID 顺序处理；基于真实收益候选仍须通过独立配对检查点的风险与调用预算审核。审核使用冻结包的实际后置规则概率 π，分别计算 πH 与已验证草稿调用+πΔcalls。它是独立检查点证据，不是本次 live 任务的个体反事实。

按任务/模板依赖组计算 bootstrap 诊断；风险额外保留有限支持的上界并记录候选数调整。只有字面恒 Silent 和显式全局 no_memory 协议可使用结构性零干预风险，不能因为一批上下文样本 p=0 就宣称整个上下文策略零风险。no_memory 的局部记忆/gate 调用开销为零，完整任务成本仍照常计入效用和报告，不是零成本 actor。支持不足、未知或无可行候选时明确 no_selection。选择集的胜出结果仍有选择乐观偏差，锁中注明最终 test 未打开；独立最终测试承担未见任务评价。

本地路径检查和哈希绑定说明软件中的执行先后，不是可信时间戳，也不能证明使用者从未看过其他结果。正式研究的候选和阈值仍需预登记。

## 不可恢复任务的保守选型

不可恢复环境显式采用 `conservative-policy-selection-plan.v1`，使用 `plan-conservative-selection`、`collect-conservative-selection`、`select-conservative-policy`。它不是配对审核失败后的自动降级，不创建独立目标快照，也不生成 H 或反事实费用。

从各候选完整 live rollout 的原始 input、preparation 和 assignment 重核状态、实际 π、草稿调用数和剩余预算 R。每个有冻结状态的检查点取风险上界 π（最坏 h=1），调用上界 1+πR。保持 Silent 的有状态检查点仍计入草稿成本；无检查点任务仍计入完整回报，局部约束覆盖另报。有限支持/全候选完整/未知阻断/前瞻目录/不可覆盖规则与配对选型一致。

该方案可能过于保守而选不出有用提醒策略；这是缺少个体配对信息时明确的限制，不能用单臂成功率代替 H。选择锁保存 conservative 协议身份，不能重标为实测配对风险；最终 test 仍需单独冻结计划。

选型要求每个实际 actor 响应的 model/fingerprint 身份完整并一致，任何响应未知都会阻止全计划选出赢家；配置中的名称不能替代缺失的实际身份。两种选型协议同样检查，完整已知身份旧锁继续可核查。真实服务需满足此门禁，不能自行补造指纹。

## 最终冻结 test 计划与报告

`plan-final-evaluation` 只在创建计划时重核配对或保守选择锁，保存自包含锁快照、选中包和固定基线、完整 test manifest/资产、配置、实际服务身份、分配/统计种子和输出路径。`collect-final-evaluation` 只执行此计划，`report-final-evaluation` 重核本次原始事件并导出报告；执行与汇总无需重新读取历史训练、校准或选型结局。

同一任务/模板/已知依赖连通组整体分配给一个冻结策略，每组的随机抽签及已知策略分配概率事先记录。它不是检查点纳入概率，也不是 gate 的提醒概率。每任务只尝试一次，不补跑空策略组，不按结果重新随机化。实际任务批次与顺序写入计划；环境/服务随时间变化不是此离线协议的自动保证。

最终角色真实保存为 test。只有新计划授权路径能采样并执行 test；原有训练/采集/校准/选型入口仍拒绝 test。运行不训练、不调整阈值或重写选择。缺少已审核赢家、输出已存在或身份/资产不同会在请求前失败；pending保持不明状态且不重试。

报告同时提供所分配任务的描述性均值、按全部计划任务分母计算的 Horvitz–Thompson 边际估计和 selected−baseline 差异。按原随机化组联合 bootstrap，保留组大小差异；分别报 task/group ESS。HT 估计可能超出成功率的自然边界，不截断以制造好看数值。未知被分配结局/费用会令对应总体估计不可用，已知行均值仅是描述；不把另一策略未观察的潜在结果当缺失并补值。样本/组不足则不给区间。

报告涵盖完整 pass@1、效用、检查点/记忆覆盖、提醒分配与实际请求、绝对 actor/token/工具/费用/耗时，以及 family/mechanism/template 的预声明分层。未完成执行或实际模型身份不完整会禁用总体与分层推断，原始观察仍保存。所有区间都是依赖独立组/支持假设的诊断，不是自动成立的多重比较保证；共享来源库限制继续保留。

新最终计划另登记 `checkpoint_coverage_report`，新报告使用 v2，按已冻结检查点的 v/ρ/e 描述覆盖、结局已知数、提醒和已知行均值。没有冻结特征的任务单列，未完成决策不能标成已知 Silent；这些是所选检查点的描述，不能解释成全任务总体因果子组效应。旧计划没有此开关时继续生成原 v1 报告，已有结果不被静默迁移。

最终单臂 live rollout 没有个体 H/rescue。报告只引用选择锁中的验证风险证据及其配对或保守协议范围，不能把它写成已经测得 test 回退。额外真实配对 test、来源/机制留出、噪声库、第二档 actor 与完整外部基线实验仍需各自预登记和实际运行。
