## 软件与研究的分界

本目标交付可运行、可验证的核心训练与评估软件，以及贯穿四部分的离线演示。正式样本量、任务清单、模型部署、δ/B、成本权重、置信水平与停止规则应通过显式配置在真实采集前冻结；测试配置只验证算法和边界，不能成为研究参数的经验依据。

配对数据支持指定恢复/种子耦合下的回退风险；只有单臂数据时不能声称已观测个体回退风险。未知成本和结局不能补零；来源、任务、模板、依赖组和机制的留出范围必须声明。单个固定来源库条件下的验证不能声称来源留出泛化。

单臂 DR 统计可独立使用；当前单臂 bandit 与冻结流程仍需兼容的配对 model/calibration/warm_gate。纯单臂数据从零初始化与校准尚未实现。预算限局部 actor 调用，校准/组区间为明确假设下的诊断；这些首版范围不等于 proposal 所有模型与实验对照已经完成。

Inspect 按第四张图保留为独立可选扩展，需要额外两阶段随机日志。原论文完整基线系统复现、两档真实 actor 实验、真实自然/四格/噪声库样本和正式研究结论均需独立执行条件；核心软件完成时仍应如实列为尚未完成的真实研究工作，不以脚本模拟冒充这些结果。
