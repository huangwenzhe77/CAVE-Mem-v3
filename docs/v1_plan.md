## 1. 这一版要交付什么

**V1 是可审计、可恢复、每条目标 rollout 至多一个检查点的 Silent/Remind 配对数据闭环。**

复用已经实现的来源记忆、目标抽样、top-1 检索和干预前状态，补齐目标检查点恢复审核、配对计划、瞬时提醒、两臂续跑、成本记录与配对标签。最后在符合已审核协议的真实小批次上验证流程，输出包含失败与未知的报告。

V1 的成功标准是数据和实验过程可信。提醒可能没有收益，甚至可能导致回退；零合格记忆、零合格检查点或恢复不兼容也是需要保留的结果，不能为了产出正结果放宽门槛。

V1 不包括策略训练、最终 test 评估、不可恢复环境的单臂执行、Inspect、多检查点干预、actor 微调或 PPO/GRPO。第三、四阶段只在本文定义后续里程碑，不由本轮规划自动授权实施。

## 3. 已确定的研究与工程规则

### 3.1 新来源实验的入库规则

用户于本轮明确选择：**K=2，两组修正续跑都终局成功，且平均效用差严格大于 `acceptance_epsilon`。**

新规则可写为：

`v=1 ⇔ 两组均完整有效 ∧ Y_corrected,1=Y_corrected,2=1 ∧ mean(R_corrected−R_original)>epsilon`。

两组完整有效但成功/均值条件不满足，`v=0`；缺组、恢复异常、调用异常或无效修正等证据不可用时，保留 `v=?`。成功不替代效用差；均值超过阈值也不替代两次修正成功。K=2 是工程 pilot 的规则，不是统计置信保证。

当前 `source-evidence.v5` 只要求完整有效 K 组和平均差超过阈值，**尚不符合新规则**。V1-02 负责新版本。旧 plan/evidence/bank 按原版本保留与审计，不用新规则重写历史文件、不静默迁移。新 pilot 必须绑定新规则身份；旧临时 pilot 库不得直接作为新规则已通过的证据。

### 3.2 数据和信息边界

- `history` 只生成来源记忆；真实 V1 目标 pilot 先限定 `target_train`。`validation` 留给之后的校准/选择，`test` 保持未触碰。
- 任务、模板和已知依赖的连通组不能跨分区。来源 lineage/机制留出需要独立清单与记忆库，不能仅添加文本标签就宣称完成。
- 主库只接纳合格来源证据。教师解释是机制假说；来源直接修正有效不等于目标文字提醒有效。
- `ρ` 用当前公开谓词重算；`e` 使用冻结动作暴露规则；未知保持 `?`。相似度不能代替 `ρ/e`，连续 `d` 不自行解释为适用门槛。
- **目标样本不以 `ρ=e=1` 为准入条件**；必须保留 `(ρ=1,e=0)` 及未知情况，否则无法检验无谓提醒和回退。硬门控留作基线。
- actor、encoder、gate 不接触私有评分材料、未来结局或原始审计快照。公开来源证据摘要可以使用，完整 `audit_sources` 不得进入提示词。

### 3.3 策略、采集与执行是三个接口

| 接口 | V1 定义 | 明确不代表什么 |
| --- | --- | --- |
| `PolicyOutput` | 未来 gate 输出 `pi_silent`、`pi_remind`，和为 1；绑定模型/特征版本、状态 hash、拒绝原因；收益/风险预测可以缺失 | 不改写 `a0`，不输出 shell 动作，不自行分配处理 |
| `EligibilityRecord` | 检查来源规则、状态完整性、协议、恢复与预算是否满足配对要求 | 不是“提醒是否有用”的预测，不用目标结果判断 |
| `PairPlan` | 固定两臂、先后顺序、种子/耦合、预算、提醒版本及输入身份 | `order_probability` 不是单臂行为 propensity |
| 后续 `AssignmentRecord` | 单臂采集才记录 `z` 和 `b(z|x)>0` | 不等于未来学习策略 `πθ`，不生成已观测配对 `H` |

V1 不训练或伪造 gate：配对采集不需要先得到策略推荐；状态记录 `policy_status=not_trained`，预测保持缺失。未来部署才依据学习策略选择一次 Silent/Remind。

配对协议按现有实验设计 §2.2 操作化：两臂都执行，随机化先执行哪一臂，推荐 `P(Silent-first)=P(Remind-first)=0.5`，在计划里冻结。它是对提案 cloneable 分支的明确实现解释，不能声称因此产生了单臂随机日志；未来单臂路径另立协议。

### 3.4 状态与时间顺序

```text
冻结任务/模型/规则与来源库
  → 无记忆目标 rollout，在动作前在线选择至多一个点
  → actor 只生成一次 a0 → top-1 检索 → 冻结 x_t
  → 校验 prepared 记录和技术资格
  → 冻结 PairPlan（尚未执行两臂）
  → 两个独立恢复分支，按计划顺序执行 Silent / Remind
  → 私有 verifier 终局评分 → 分臂原始日志
  → 独立重算 D / H / rescue / 成本与覆盖报告
```

现有 `prepare-target` 继续以 `not_assigned`、`outcome_access=none` 结束；下游计划另存，不修改已冻结的 `a0/x`。无选择、无候选、特征不全、预算不足、恢复不支持和执行错误必须区分并保留。

Silent：从恢复检查点验证并执行原封不动的缓存 `a0`，前置 actor 调用为零。无效动作按预登记规则记录，不能换成“更安全”的动作。

Remind：只使用允许的公开来源字段生成短提醒，调用同一冻结 actor 重提一次动作，再按相同权限验证、执行。提醒只注入这次调用，后续普通续跑不持续注入；重提/解析失败不能偷偷再问一次。保持来源 actor 提示渲染器拒绝提醒的原保护，新增目标专用入口。

两臂使用相同的动作有效性和终止规则：actor 提出不允许的动作是执行行为，不能只因发生在 Remind 就当作基础设施缺失剔除。权限系统、服务或恢复本身故障另记基础设施异常；解析错误的处理也须在合同中对两臂一致预登记。

### 3.5 预算与成本

V1 推荐在合同中冻结以下统一口径，具体数值在真实 pilot 清单确定：

1. 缓存 `a0` 已消耗一次模型调用，其成本计入共同开销。
2. `R` 为产生 `a0` 后的剩余总模型调用数；配对前要求 `R≥1`，为重提动作预留 1 个 intervention 槽，两臂普通续跑额度相同，均为 `R−1`。Silent 不把空余槽换成更多续跑调用。
3. 环境剩余步数为 `min(研究总步数上限−已执行步数, 环境当前剩余步数)`，已是剩余值的字段不能再次扣减。两臂当前所选动作各消耗一个环境步，恢复检查不冒充 actor 工具动作。
4. 共同草稿/检索/特征开销、提醒额外调用、分臂续跑、恢复/verifier 运维成本分别记录。策略部署总成本只计一次共同开销；实验实际支出包含两个分支及审核开销，两者分别报告。
5. 实际 token、工具次数、耗时与可用费用照实记录；未知成本不能补零。当前运行合同没有全局 token 上限，不声称已实现；需要时另开任务。

该分配同时保持同一总上限和相同普通续跑额度。预算不足归技术不合格，先于执行记录；不可借用未登记额度、事后增加预算或悄悄重试。

### 3.6 恢复协议与适用范围

V1 仅覆盖经过审核的 `stateless-offline-filesystem-v1`：单容器文件任务、动作边界恢复、无跨动作 shell/后台服务状态。复用既有镜像快照与公开历史恢复，但必须验证具体目标检查点在原环境关闭后仍可恢复、分支文件互不污染、任务资产和镜像身份不变。

快照 hash 相等只是检查之一；仍需实际文件探针、隔离检查和完整依赖范围审核。服务器响应 seed/fingerprint 只记录其实际能力，不能证明远端 RNG 或权重完全一致。配对风险是声明随机协议 `ξ` 下的量。

恢复不认证或失败时，停止该配对并保留原因，不自动降级单臂。`prepare-target` 会关闭环境，不可恢复系统若要单臂继续，需要后续同一活会话内的冻结/分配/执行 adapter。

旧 H20 pilot 的 verifier 会在运行时联网安装依赖，历史文档未把范围审核标为正式批准。真实运行前须提出并审核具体变更：将固定版本测试依赖预置于 verifier 镜像、保留官方测试/断言、记录镜像和资产 hash、确认评分语义一致；或者另建明确允许网络的协议。不能直接把旧审核布尔值改为 true。V1 优先离线方案；无法满足时报告不兼容并停止相应实验。

协议设计通过不代表镜像/adapter 已存在。若 V1-14 发现需要构建或实现依赖，先另拆一张完整任务卡并完成它，才可进入 V1-15。V1-15 审核的是任务级协议与诊断快照；V1-19 生成真实目标检查点后，V1-20 在生成配对计划前还必须逐个运行 V1-05 的恢复门禁，失败保留排除记录。

### 3.7 标签、错误与结论

完整有效 pair 才有 `D=R(1)−R(0)`、`H=1{Y(0)=1,Y(1)=0}`、`rescue=1{Y(0)=0,Y(1)=1}`。从原始结果与冻结成本权重重算；单臂、缺臂、恢复错误、调用错误不得伪造成 `H=0` 或任务失败。

报告至少包含计划/尝试/完成/有效 pair 数、任务/模板/来源独立组数、无选择和无记忆比例、`ρ/e/?` 覆盖、各臂成功、D/H/rescue、绝对成本及错误原因。同一检查点的复本不是独立任务。覆盖不足时不进行无依据的自然分布外推；抽样重加权只能使用已记录且适用的概率。
